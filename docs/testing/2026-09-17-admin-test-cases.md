# 小米汽车后台管理系统功能测试用例

> **版本:** v1.0
> **日期:** 2026-09-17
> **关联:** [测试总计划](./2026-09-17-test-plan.md) | [后台管理系统 Spec](../specs/2026-09-17-xiaomi-car-admin-spec.md)

## 1. 执行约定

- 后台完整编辑体验使用 1280px 及以上桌面视口执行,移动端仅验证基础查看。
- 每个系统角色使用独立测试账号,不得使用超级管理员代替普通角色执行 RBAC 用例。
- 所有写操作同时核对 API 响应、数据库结果和 `audit_logs`。
- 查看完整手机号、导出、发布、角色修改等敏感操作必须单独核对权限与审计。

| ID | 优先级 | 前置条件 | 操作 | 预期结果 |
