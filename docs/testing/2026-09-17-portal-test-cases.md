# 小米汽车门户网站功能测试用例

> **版本:** v1.0
> **日期:** 2026-09-17
> **关联:** [测试总计划](./2026-09-17-test-plan.md) | [门户网站 Spec](../specs/2026-09-17-xiaomi-car-portal-spec.md)

## 1. 执行约定

- 每条用例在 Chrome 最新稳定版执行;核心流程补充 Safari、Edge、Android Chrome 和 iOS Safari。
- API 响应应包含可追踪的 `requestId`;错误不得包含堆栈、SQL 或内部路径。
- 涉及短信时,功能回归可使用契约 Mock;标记“真实通道”的用例必须使用火山引擎短信和受控手机号。
- 涉及微信时,使用已登记测试域名和微信测试应用。
- 除明确说明外,预期页面语言为简体中文,时区为 `Asia/Shanghai`。

| P-SEC-007 | P1 | 发送超大 JSON、未知字段和错误类型 | 返回 400/422,服务稳定且错误明确 |

## 9. 门户冒烟集

每次部署后按顺序执行:

1. `P-WEB-001`:首页与已发布内容。
2. `P-INV-001`:车型详情与库存。
3. `P-SMS-003`:短信 Provider 受理。
4. `P-AUTH-001`:手机号注册。
5. `P-AUTH-009`:密码登录。
6. `P-WX-004`:已绑定微信登录。
7. `P-ORDER-001`:0 元下定。
8. `P-ORDER-007`:取消并释放库存。
9. `P-TD-001`:创建试驾预约。
10. `P-SEC-001`:未授权访问隔离。
